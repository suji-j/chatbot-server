## 지능형 챗봇 서비스
사용자는 자연어로 챗봇에 질문을 던지고, 챗봇은 날씨 정보, 교통 정보, 레스토랑 추천 등 다양한 정보를 제공할 수 있습니다.

이를 위해 자연어 처리(NLP) 기술을 활용해 사용자의 질문을 정확하게 이해하고, 외부 API와의 연동을 통해 필요한 데이터를 수집하여 적절한 답변을 사용자에게 전달합니다. 

이러한 솔루션은 사용자에게 실시간으로 필요한 정보를 제공하며, 카카오톡과 같은 메신저 플랫폼과 연동하여 간편한 접근성을 제공합니다.

카카오 챗봇을 통한 요청을 응답하는 flask REST API입니다.

---
### 주요기능
- **실시간 날씨 정보 제공**: 사용자가 입력한 지역의 현재 날씨와 날씨 예보를 제공합니다.
- **교통 정보 제공**: 출발지와 목적지를 기반으로 실시간 교통 정보와 추천 경로를 제공합니다.
- **레스토랑 추천**: 사용자의 위치를 기반으로 레스토랑을 추천하고, 레스토랑 정보를 제공합니다.
- **자연어 처리 (NLP)**: 사용자의 발화를 이해하고, 적절한 대화 흐름을 유지하며 사용자의 요청에 대응합니다.
---

|:-:|:-:|

---

### 1️⃣ 프로젝트 방향

챗봇은 메신저 플랫폼(카카오톡)과 연동되어 사용자의 명령을 처리합니다. 사용자는 날씨 정보나 교통 상황, 추천 레스토랑을 물어볼 수 있으며, 챗봇은 사용자 질문에 맞는 정확한 답변을 실시간으로 제공할 수 있습니다.

---
### 2️⃣ 필수 패키지

이 프로젝트는 특정 Python 패키지에 의존합니다. 패키지 의존성을 관리하기 위해 `requirements.txt` 파일을 사용하고 있습니다.

---
### 3️⃣ 가상 환경 설정

프로젝트의 패키지와 의존성을 독립적으로 관리하기 위해 가상 환경을 사용하는 것이 좋습니다. 가상 환경을 생성하고 활성화하는 방법은 다음과 같습니다:

#### 가상 환경 생성 및 활성화

1. **가상 환경 생성:**

   ```bash
   python -m venv venv
   ```

2. **가상 환경 활성화:**

   - **Windows:**

     ```bash
     .\venv\Scripts\Activate
     ```

   - **macOS/Linux:**

     ```bash
     source venv/bin/activate
     ```

---
### 4️⃣ 패키지 설치

가상 환경을 활성화한 후, `requirements.txt` 파일을 사용하여 필요한 패키지를 설치할 수 있습니다. 다음 명령어를 사용하여 패키지를 설치합니다:

```bash
pip install -r requirements.txt
```
